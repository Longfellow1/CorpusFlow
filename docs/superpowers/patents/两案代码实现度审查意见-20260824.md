### 3.3 关键缺失特征详细说明

#### 缺失1：约束图（S3核心特征）

**交底书描述**：
```
构建维度约束图,记录:
- 互斥关系:两个维度不能同时变化
- 联动关系:一个维度变化时另一个必须跟随
- 条件激活:某个维度变化时才允许另一个维度变化
- 顺序依赖:多个维度变化必须按特定顺序进行
```

**代码现状**：
- ❌ 无 `ConstraintGraph` 数据结构
- ❌ 无 `constraints[]` 数组
- ❌ 无互斥/联动/条件激活/顺序依赖的类型定义
- ❌ 约束检查和冲突解决逻辑缺失

**影响**：这是独权S3的**核心特征**，缺失会导致审查员质疑"约束关系如何表达和处理"。

#### 缺失2：预算调整机制（S5核心特征）

**交底书描述**：
```
根据约束图中的约束关系,调整原始预算使其可执行:
- 对于互斥维度,确保只有一个维度获得预算
- 对于耦合维度,将预算分配给维度组合
- 对于条件依赖,确保依赖条件满足时才分配预算
- 对于联动维度,同步调整相关维度的预算
```

**代码现状**：
- ❌ 无 `originalBudget` → `executableBudget` 转换逻辑
- ❌ 无基于约束图的预算调整算法
- 🔵 只有简单的 `ratio={normal:0.8, robust:0.2}` 双路径比例

**影响**：这是独权S5的**核心特征**，缺失会导致"可执行预算"概念无法证明。

#### 缺失3：质量反馈归因与预算调整（S6核心特征）

**交底书描述**：
```
将质量结果归因到生成轨迹中的语义维度变化:
- 统计各维度的通过率、拒绝原因分布
- 根据质量反馈调整各维度的后续预算或变化策略
- 通过率低的维度降低预算或调整变化策略
- 通过率高的维度可增加预算
```

**代码现状**：
- ❌ 无质量门筛选逻辑
- ❌ 无维度级通过率统计
- ❌ 无基于反馈的预算调整机制
- ❌ 单轮生成，无多轮状态承接

**影响**：这是独权S6的**核心闭环**，缺失会导致"反馈驱动优化"无法证明。
